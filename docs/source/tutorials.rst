Tutorials
==================

Two walkthroughs of the same workflow, one per supported code. The full
workflow tutorial runs it with ``VASP`` on the reference calculation set for
Cu\ :sub:`2`\ GeS\ :sub:`3`; the CASTEP tutorial runs it with ``CASTEP``,
covering ``.cell``/``.param`` generation and reading ``.bands`` and OptaDOS
output back. Everything between the calculation outputs and the figure of
merit is the same code in both.
